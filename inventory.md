# VectorCraft icon inventory

Source: the VectorCraft repository; source paths below are relative to its root.

## Coverage and interpretation

- **273 registered SVG IDs:** 253 have static production drawing/tool references; 20 are registry-only assets with no static production caller. Each ID appears below and in `inventory.json`, with a `sourceSvg` path.
- **103 tool roles:** 92 main-catalogue roles and 11 add-on roles. Shared current artwork and proposed distinct artwork appear in separate columns.
- **96 cursor enum roles:** the 93-entry `GLYPHS` list omits `Busy`, `NotAllowed`, and parameterized `RotateToward`. Expanding the latter to eight octants produces **103 cursor variant rows**. Current fallbacks/reuse resolve to **66 artwork families**, including two native states.
- **131 noncursor control roles:** 127 separate procedural artwork records after current-source aliases and reuse of the registered `image` SVG. The tables preserve each role.
- **47 dynamic painter families**, **9 font faces**, **23 identity rendition paths in 3 identity families**, and **17 content/installer image files**. Native platform cursors have one separate family record.
- `inventory.json` contains **543 artwork/content/family records**. The schema is `{id,function,category,usage,shortcut,equivalent,verdict,reason,sourceSvg,procedural}`. Role aliases belong in `tool-roles.json`, `procedural-scope.json`, and `role-design-coverage.json`; they do not inflate unique-artwork records.

### Shortcut evidence

Shortcuts here are executable source defaults, not guesses from icon names. Tool defaults come from `crates/tools/src/catalog.rs:20-138` and `addons.rs:20-37`; command defaults come from engine `cmd!` specifications and `menus/ui_commands.rs`; panel defaults come from `shortcut_editor.rs:165-185`. `shortcut_editor.rs:156-160` gives engine commands precedence over UI defaults. `keymap.rs:233-240` adds Shift+, and Shift+. as secondary bindings for last solid color and last gradient.

`Cmd` is the source command modifier, displayed as Command on macOS and normalized for other platforms. `~` names the backtick-key tool binding. User shortcut overrides, imported shortcut sets, platform conflicts, keyboard layout and active text editing can change effective runtime dispatch. No live application shortcut state was queried; `unassigned` means no source-default binding for that function, not a claim about the user's configured keymap. Cursor-state rows have no independent action binding.

### Verdicts and scope

`redraw` means retain the evidenced function while drawing new geometry under the 24×24 / 1.6 px contract. `wrong metaphor` identifies a source function mismatch or a shared symbol that conceals different operations. `keep` retains identity, content, native rendering, live value previews, or an unused registry entry; it does not assert legal clearance or certify old geometry. I assessed source function mappings, not visual similarity to other products.

Action icons are separate from generated thumbnails, user artwork, font glyph specimens and continuous controls. The app/family marks and platform renditions remain identity assets. This inventory does not propose a rebrand.

### Native platform cursor variants and fallback roles

Native image shapes come from the platform and have no application SVG master. Keep platform ownership. Window resize uses `titlebar.rs:140-151`; custom-toolbar dragging uses `custom_toolbars.rs:655-663`; document dragging uses `document_drag.rs:187`; long operations use `app.rs:633`. These states have unassigned independent shortcuts and a keep verdict.
